# X GeWu

**简体中文** · [English](README.en.md)

**清理旧帖，理顺关注。**

X GeWu 是为 X / Twitter 打造的油猴脚本。按日期和数量批量清理内容，用三种颜色看清关注关系，让整理账号更直观、更省心。

**v0.3.14 · Tampermonkey · MIT**

[安装脚本](https://raw.githubusercontent.com/gegewu26-source/X-GeWu/main/X-GeWu.user.js) · [下载最新版](https://github.com/gegewu26-source/X-GeWu/releases/latest) · [关注 GeWu，获取更新](https://x.com/gegewu203)

## 功能亮点

- **按日期清理**：选择起止日期，批量删除普通帖子、回复和引用帖，或取消自己的转帖。
- **数量由你掌控**：达到设定的候选上限立即停止扫描，清晰显示候选、待处理、本次成功和累计成功数量。
- **扫描更顺畅**：区分新帖子与页面滚动，兼容虚拟列表；加载长期无进展时保留结果并暂停，恢复后继续扫描。
- **三色关注关系**：蓝色互关、绿色仅对方关注你、红色仅你关注对方，颜色直接覆盖账号卡片。
- **轻松整理关注**：扫描未回关候选，点击用户名在新标签页查看主页，再按确认名单批量取消关注。
- **保护重要账号**：设置保护名单，保留你想继续关注的人。
- **先模拟，再执行**：帖子清理与取关均默认开启模拟模式，支持暂停、继续、停止及取消关注扫描。
- **无需 API 密钥或服务器**：直接操作网页，配置与统计保存在浏览器本地。

颜色反映当前页面可识别的关系；互关历史只记录脚本实际观察到的状态，未回关不代表对方曾经取关你。

## 安装

1. 在浏览器中安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 点击上方“安装脚本”，确认安装。
3. 打开或刷新 X，即可看到 **X GeWu** 面板。

更新时替换原脚本，避免同时启用多个副本。

## 使用

**清理帖子**：进入自己的主页，选择类型、日期和数量，点击“计算删除数”。先保留 Dry Run 演练，核对范围后关闭模拟模式并开始删除。

**管理关注**：打开自己的“正在关注”列表，设置保护名单和数量，点击“扫描关注”。查看候选主页，先模拟，再确认取消关注。“关注者”列表也支持关系标色。

实际删除不可撤销，请先保留需要的内容。
